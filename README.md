# ZS-Privet-ltd-web
website for ZS private limited business presence 



Welcome to the repository of **ZS Private Limited**, a premium, single-page responsive enterprise portal designed to highlight cutting-edge software development services, AI integrations, cloud solutions, QA automation, and career-defining student internship opportunities.

---

## 🌟 Executive Summary & Features

This website is designed with a modern **Fortune-500 luxury aesthetic** inspired by design leaders like Apple, Microsoft, Stripe, and AWS.

- **🎨 Modern Dark Mode Aesthetic:** Deep Navy Blue backdrop (`#05070E`), glassmorphic panels (`backdrop-filter`), subtle gradients, and crisp typography (`Plus Jakarta Sans` & `Inter`).
- **📱 Fully Responsive:** Adaptive layouts optimized across Desktop, Laptop, Tablet, and Mobile viewport sizes.
- **⚡ Zero External Asset Dependency:** Built using pure HTML5, Tailwind CSS CDN, Lucide Icons, and vectorized inline SVG illustrations to guarantee 100% uptime without broken image links.
- **💼 Comprehensive Business Sections:**
  - **Hero Section:** Animated metrics counters, call-to-actions (Inquiry, Internship, Consultation), and floating tech tags.
  - **About Us:** Dual-mission statement highlighting client excellence and student empowerment.
  - **Core Services:** Web, AI/LLM, Cloud/DevOps, QA Automation, Mobile Apps, and Data Analytics.
  - **Technology Stack:** Highlighting 30+ enterprise technologies (Spring Boot, React, Next.js, Python, Selenium, AWS, etc.).
  - **Portfolio & Case Studies:** Highlighted enterprise software solutions with clean UI mockups.
  - **Career Launchpad & Internship Portal:** Direct application form for students with college details and domain preferences.
  - **Project Inquiry & FAQ:** Interactive accordions and project estimate request forms.

## 🚀 Quick Start / Deployment

Since this website is completely self-contained in a single lightweight file, setup and deployment require no complex build tools or `npm install` steps.

### Local Execution
1. Download or clone this repository.
2. Ensure `input_file_0.png` (Company Logo) is present in the root directory alongside `index.html`.
3. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Safari, Firefox).

### Hosting on GitHub Pages / Vercel / Netlify
1. Push `index.html` and `input_file_0.png` to your GitHub repository.
2. Enable **GitHub Pages** under repository settings (`Settings -> Pages -> Branch: main`).
3. Your live portal will be deployed instantly!
